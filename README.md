---

### 📌 Featured

**[xamarin-to-maui-migration](https://github.com/appflowllc/xamarin-to-maui-migration)** —
A complete, decision-documented migration of a Xamarin.Forms MVVM app to **.NET 10 / MAUI**.

Not a "Hello MAUI" template. It takes a representative Xamarin.Forms app — imperative C#-built UI,
a dead SQLite dependency, hand-rolled navigation and messaging — and migrates it layer by layer to
modern MAUI: Shell navigation, constructor DI, `WeakReferenceMessenger`, CommunityToolkit MVVM,
XAML with compiled bindings, and a custom **renderer converted to a true native handler** (a step
the common reference sample stops short of). Every non-trivial decision is recorded in a running
migration log — the *reasoning*, not just the result. Builds and runs on .NET 10.
